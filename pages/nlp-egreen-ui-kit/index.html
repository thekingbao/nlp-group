Lưu ý quan trọng

Đây là UI Kit / App Template, không bao gồm backend, admin panel, cơ sở dữ liệu, máy chủ xác thực, cổng thanh toán, live chat server hay bất kỳ API service nào.

Tính năng tìm kiếm trạm sạc là UI demo với mock data; bản đồ, vị trí trạm, lập lịch tuyến đường và tính năng trạm lân cận đều là màn hình UI phi chức năng — không tích hợp Google Maps, geolocation, navigation hay live API.

Người mua cần tự tích hợp map SDK, location services, backend và APIs để có chức năng thực tế trên môi trường production.

Tất cả màn hình chỉ dùng cho mục đích demo UI. Không có dữ liệu thực, không có kết nối mạng thực trong bản demo.

Tính năng

Tính năng nổi bật

Bộ công cụ UI đầy đủ được xây dựng theo chuẩn Flutter hiện đại, tối ưu cho trải nghiệm người dùng trên cả Android lẫn iOS.

Cross-Platform Ready

Hỗ trợ đồng thời Android và iOS từ một codebase duy nhất. Triển khai nhanh, tiết kiệm thời gian phát triển lên đến 60%.

Powered by Dart

Toàn bộ mã nguồn viết bằng Dart thuần — ngôn ngữ tối ưu cho hiệu năng Flutter, biên dịch native, khởi động siêu nhanh.

Modern UI/UX Design

Thiết kế theo chuẩn Material 3 kết hợp ngôn ngữ thiết kế EV riêng — dark mode mặc định, tương phản cao, dễ đọc khi lái xe.

Professional Layouts

Các layout đã được cân chỉnh tỉ mỉ: khoảng cách nhất quán, grid căn chỉnh pixel-perfect, phù hợp với mọi kích thước màn hình.

Fluid Animations

Hiệu ứng chuyển màn hình mượt mà, micro-interactions phản hồi tức thì — tất cả chạy ổn định ở 60fps trên thiết bị tầm trung.

Rich Iconography

Bộ icon EV chuyên biệt gồm biểu tượng trạm sạc, connector CCS2/CHAdeMO, pin xe điện — đồng bộ về visual language trên toàn app.

Flexible Typography

Hệ thống kiểu chữ linh hoạt

Sử dụng Work Sans làm font chính — hỗ trợ đầy đủ tiếng Việt, scale tốt từ caption 11px đến display 48px, dễ thay thế bằng font khác.

Dynamic Theming

Hệ thống token màu linh hoạt — chỉ cần thay đổi một biến để cập nhật toàn bộ palette. Dễ dàng tích hợp brand color riêng của doanh nghiệp.

Fully Responsive

Layout thích ứng hoàn toàn từ màn hình 4.7" iPhone SE đến tablet 12.9" iPad Pro, không bị vỡ layout hay tràn nội dung.

Clean Codebase

Cấu trúc thư mục rõ ràng theo kiến trúc Feature-first, comment đầy đủ bằng tiếng Anh, tuân thủ Effective Dart style guide.

Effortless Customization

Mọi màn hình được tách thành widget độc lập, tái sử dụng được. Thêm màn hình mới, thay màu hay đổi font chỉ mất vài phút.

Built-in Splash Screen

Màn hình khởi động được thiết kế sẵn với logo animation mượt mà, hỗ trợ cấu hình thời gian và màu nền theo brand identity riêng.
