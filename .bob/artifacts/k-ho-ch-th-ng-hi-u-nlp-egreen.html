• Chữ NLP: Trắng, Bold, cân xứng

• File cần: SVG + PNG (300px, 600px, 1200px)

05 · Kế hoạch 3 giai đoạn

Roadmap triển khai

P1
Giai đoạn 1 — Nền tảng thương hiệu
Tuần 1–2 · Những thứ khách hàng thấy đầu tiên
  • 🎨
    Thiết kế Logo NLP-EGREEN
    SVG + PNG (300/600/1200px). Giữ elip navy, đổi TMT → NLP. Dùng cho web, app, ảnh sản phẩm, biển hiệu.
    Cần ngayDesigner
  • 📸
    Chụp ảnh thực tế dự án & trụ sạc
    Thay thế toàn bộ ảnh Unsplash placeholder. Cần: hero banner (1920×1080), ảnh trụ sạc 4 model, 3–5 dự án đã lắp đặt, ảnh đội ngũ.
    Cần ngayPhotographer
  • 🔑
    Điền dữ liệu thực vào Admin Settings
    google_tag (GA4 ID), business_license (MST), zalo_oa_id, Facebook/YouTube/TikTok URL thực, hotline chính thức.
    Cần ngayClient data
  • 🗺️
    Kích hoạt Google Maps API key
    Đăng ký key tại Google Cloud Console → Admin > Cài đặt → Dán vào field maps_key. Cho phép bản đồ tìm trạm realtime hoạt động đầy đủ.
    Cần ngayClient setup
  • 📱
    Lên kế hoạch App NLP-EGREEN
    Xác định scope: User App (tìm trạm, QR sạc, theo dõi pin) + Investor App (doanh thu, đối soát). Đăng ký developer account iOS/Android.
    Tuần 2Product
  • 📢
    Tạo kênh mạng xã hội NLP-EGREEN
    Facebook Page + YouTube + TikTok với handle @tramsac.nlpegreen. Đồng bộ avatar logo mới, cover ảnh thực tế, điền thông tin liên hệ đầy đủ.
    Tuần 2Marketing
P2
Giai đoạn 2 — Nội dung & Chuyển đổi
Tuần 3–6 · Tạo lead, nuôi dưỡng khách hàng
  • 🖼️
    Overlay logo NLP-EGREEN lên ảnh trụ sạc
    Dán đè logo lên 04.png, 240kw.png, loi-nhuan.png. Thiết kế thông báo giá điện với template NLP-EGREEN (thay bản TMT).
    Tuần 3Designer
  • ✍️
    Bổ sung 4 bài blog chất lượng cao
    Thêm vào 6 bài đã có: Chi phí lắp solar 2026 (bảng giá thực), Trạm sạc ROI calculator, Biểu phí điện toàn quốc, Video hướng dẫn sạc xe bằng QR.
    Tuần 3–4Content
  • 📊
    Cập nhật dữ liệu trạm sạc thực (24+ tỉnh)
    Nhập toàn bộ tọa độ GPS từ data TMT-EGREEN vào admin/db.json → projects[]. Hiển thị trên bản đồ Leaflet trang tim-kiem-tram-sac.
    Tuần 4Client data
  • 💰
    ROI Calculator trang Đối tác
    Calculator tương tác: nhập (số cổng sạc × kWh/ngày × giá điện) → ra doanh thu/tháng, 80% cho đối tác, thời gian hoàn vốn. Học từ biểu đồ loi-nhuan.png.
    Tuần 5Dev
  • 🎯
    Landing page chiến dịch đối tác nhượng quyền
    Trang riêng tối ưu chuyển đổi: Hero "Đầu tư 1 trụ sạc — Thu về X triệu/tháng", Stats ROI, Form đăng ký ngắn, Social proof (số đối tác hiện tại).
    Tuần 5–6Dev + Content
  • 📧
    Email automation cho leads
    Kết nối form leads (localStorage hiện tại) → webhook gửi về email/Zalo. Auto-reply khi có lead mới. Tích hợp Google Sheet hoặc CRM đơn giản.
    Tuần 6Dev + Marketing
P3
Giai đoạn 3 — Hệ sinh thái & Mở rộng
Tuần 7–12 · Hạ tầng kỹ thuật dài hạn
  • 📲
    Build App NLP-EGREEN User (MVP)
    React Native / Flutter. Core features: Bản đồ tìm trạm (Maps API), Quét QR bắt đầu sạc, Theo dõi % pin + chi phí, Ví điện tử nạp tiền.
    Tuần 7–10Mobile Dev
  • 🏦
    Build Investor Dashboard (NLP INVESTOR App)
    Bảng theo dõi trạm sạc theo tỉnh, doanh thu realtime, lịch thanh toán tuần, báo cáo tháng PDF. Web admin + Mobile app.
    Tuần 9–12Full-stack Dev
  • 💳
    Tích hợp cổng thanh toán
    VNPay / MoMo / Zalo Pay tích hợp vào app nạp tiền. Backend quản lý giao dịch, đối soát với trụ sạc IoT. Tuân thủ quy định NHNN.
    Tuần 10–12Backend
  • 🔌
    Tích hợp IoT — Trụ sạc ↔ Platform
    OCPP 1.6/2.0 protocol kết nối trụ sạc vật lý với backend. Realtime status (available/charging/offline), remote start/stop, power monitoring.
    Tuần 8–12IoT / Backend
  • 🤝
    Partnership Portal — Wuling / BYD / VinFast
    Trang co-branding với các hãng xe, chứng chỉ tương thích, khuyến mãi bundled (mua xe + lắp trạm sạc nhà). B2B sales funnel riêng.
    Tuần 11–12Business Dev
